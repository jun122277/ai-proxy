# Security policy

This repository is an SRE learning project under active development. There is
no production support commitment. Fixes target the latest `main` branch; older
commits and demonstration images do not receive backported security updates.

Please report suspected vulnerabilities privately through
[GitHub private vulnerability reporting](https://github.com/jun122277/ai-proxy/security/advisories/new).
Include the affected commit, reproduction steps using synthetic data, and the
impact. Do not include real API keys, prompts, or customer data in a report or
public issue. There is no guaranteed response time.

Public examples must use placeholder credentials. Runtime credentials must not
be stored in this repository, container layers, logs, or traces.
